# justview downloads

This repository hosts public release assets for justview.

The application source repository is private. This repository contains only
downloadable builds, checksums, and installer scripts used by justview.app.

## Install

Linux and macOS:

```sh
curl -sSL https://raw.githubusercontent.com/pascalwiemers/justview-downloads/main/scripts/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://raw.githubusercontent.com/pascalwiemers/justview-downloads/main/scripts/install.ps1 | iex
```
